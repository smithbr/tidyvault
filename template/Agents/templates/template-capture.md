# Capture template

Part of the [[README]]. A blank scratch note for Cmd+Shift+I (QuickAdd, "Capture to inbox"): it opens `_captures/capture-<timestamp>.md`, empty, with the cursor in it, and no prompt. Write anything; no title, fields, or sections needed. The [[role-vault-intake]] files it like any capture note ([[organization#Capture notes]]).
